# 源端 vs 迁移后基准对齐框架

本目录为 AOI 迁移项目（SP-2025140 → lmv-2026）的「源端基准 vs 迁移后输出」diff 对齐框架占位。

## 状态

**待人类提供源端基准数据后填充 diff 脚本。**

## 背景

迁移/重构项目的测试核心是"迁移后行为与源端一致"——diff 测试优先于功能测试。
本框架计划包含：

- 源端关键行为输出快照（工站状态机转移序列、IO 时序、握手信号序列、超时阈值等）
- 迁移后对应输出
- diff 脚本：逐项比对 + 误差阈值（如时序 ±N ms、状态序列完全一致）

## 依赖

- 源端基准数据：需人类从 SP-2025140 源端采集（现场运行抓取或源端测试日志导出）
- 数据分级：若含真实客户数据，标 D2/D3，不入公开区

## 当前覆盖

软件层契约回归已由 `tests/Luster.Module.Motion.Regression.Baseline.Tests/` 覆盖
（枚举契约 + 纯逻辑语义锁定，五类 Suite：StateMachine/ModeSwitch/IOAxis/Handshake/Timeout）。
