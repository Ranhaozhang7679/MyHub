# JunRudderVCM 使用 SOP

> 钧舵(JunRudder) GSFDmini 伺服驱动器 + 音圈电机执行器
> 通信: EtherCAT(CIA402) via 固高(GoogolTech)板卡
> 参考文档: GSFDmini伺服驱动器用户手册-20250723.pdf、驱动器力控上位机调用流程.pdf
> 参考Demo: GENECForceControlDemoCSharp

---

## 1. 硬件与接线

### 1.1 系统组成

| 组件 | 型号 | 说明 |
|------|------|------|
| 控制卡 | 固高 EtherCAT 板卡 | EtherCAT 主站 |
| 驱动器 | GSFDmini | 低压伺服驱动器，内置力位控制 |
| 执行器 | 钧舵音圈电机 | 含编码器 |

### 1.2 关键特性

| 特性 | 说明 |
|------|------|
| 力控方式 | 驱动器内置**开环力控**(P96)，SDO配参数后驱动器自主完成，上位机仅触发+监听状态机 |
| 压力反馈 | 0x201Bh 模拟量(-10V~10V → -32768~32767)，线性标定转压力 |
| 运动流程 | 快进 → 一段速度(逼近) → 二段速度(探测) → 保压 → 回退 |
| 位置单位 | mm × PerPluse(脉冲/mm) → 脉冲数写入 SDO |

### 1.3 力控方式说明

GSFDmini 驱动器支持4种力控方式（详见《驱动器力控上位机调用流程》）：

| 方式 | 名称 | 触发方式 | JunRudderVCM使用 |
|------|------|----------|-----------------|
| 一 | 开环力控(动态切换) | 0x2016上升沿触发，驱动器内部状态机(0x201A) | **当前使用** |
| 二 | 开环力控+开环补偿 | 同上 + 0x203C/0x203F 压力补偿 | 否 |
| 三 | 闭环力控(动态切换) | 同上 + 0x202F/0x3020 闭环压力控制 | 否 |
| 四 | 位置+位置力控(外部控制) | 上位机手动位置运动+扭矩限制+6077h监测 | 否(注) |

> **注:** 方式四"两段位置力控"为上位机手动控制方式（DHRoboticsVCM使用此方式）。GSFDmini 自带内置力控，JunRudderVCM直接使用方式一即可。

### 1.4 接线要点

- EtherCAT 网线连接: 控制卡 Out → GSFDmini In → 下一从站(如有)
- 编码器线: 驱动器自带，无需额外接线
- 模拟量输入: 压力传感器信号接入驱动器模拟量端口(0x201B 对应通道)

### 1.5 EtherCAT 配置

1. 使用固高配置工具生成 ENI 文件
2. 确保 PDO 映射包含:
   - TxPDO: 0x6041(状态字)、0x6064(位置反馈)、0x201B(压力反馈)等
   - RxPDO: 0x6040(控制字)、0x6060(运行模式)等
3. 软着陆力控参数通过 SDO 写入，不需要额外 PDO 映射

## 2. 动作类型总览

| 动作类型 | 枚举值 | 说明 | 典型用途 |
|----------|--------|------|----------|
| 使能 | ServoOn | 伺服使能 | 开机初始化 |
| 复位 | Reset | 清除报警+重新使能 | 异常恢复 |
| 失能 | ServoOff | 伺服下使能 | 停机/维护 |
| 回零 | Home | 标准回零(轴卡预设参数) | 通用场景 |
| 非标回零 | HomeNonStandard | SDO写入回零参数后回零 | 需要自定义回零模式/速度 |
| 硬着陆 | HardLanding | 绝对定位运动 | 点位移动 |
| 软着陆 | SoftLanding | 驱动器内置开环力控(P96) | 力控压装 |

### 3.4 回零 (Home)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 动作类型 | Enum | — | Home |
| 21 | 回零超时(秒) | int | 60 | 等待回零完成的超时时间 |

`_axis.Home()` → `_axis.CheckHomeDone(HomeTimeout)` → `OutResult = true`

---

### 3.5 非标回零 (HomeNonStandard)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 动作类型 | Enum | — | HomeNonStandard |
| 17 | 回零模式代码 | short | 0 | CIA402回零方式，如1~35、101~104 |
| 18 | 回零高速(mm/s) | double | 50 | 快速搜索速度，内部×PerPluse转脉冲/s |
| 19 | 回零低速(mm/s) | double | 10 | 慢速搜索速度，内部×PerPluse转脉冲/s |
| 20 | 回零加速度(mm/s²) | double | 1000 | 内部×PerPluse转脉冲/s² |
| 21 | 回零超时(秒) | int | 60 | 等待回零完成的超时时间 |

**执行流程:**
```
1. SDO写入回零参数:
   - 0x6098.0 → 回零模式代码
   - 0x6099.0 → 回零高速(mm/s × PerPluse → pls/s)
   - 0x6099.1 → 回零低速(mm/s × PerPluse → pls/s)
   - 0x609A.0 → 回零加速度(mm/s² × PerPluse → pls/s²)
2. 启动回零: _axis.Home()
3. 等待完成: _axis.CheckHomeDone(HomeTimeout)
4. OutResult = true
```

### 3.6 硬着陆 (HardLanding)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 动作类型 | Enum | — | HardLanding |
| 2 | 目标位置(mm) | double | — | 绝对定位的目标位置 |
| 3 | 位置上限(mm) | double | — | 到位后实际位置的上限判断值 |
| 4 | 位置下限(mm) | double | — | 到位后实际位置的下限判断值 |
| 5 | 运动速度(mm/s) | double | 50 | 运动过程中的速度 |
| 6 | 加速度(mm/s²) | double | 1000 | 运动加速度 |
| 7 | 减速度(mm/s²) | double | 1000 | 运动减速度 |

**内部流程:**
```
MoveAbs(目标位置, 运动速度, 加速度, 减速度)
→ CheckMotionDone(等待运动完成)
→ 读取实际位置
→ 判断: 下限 ≤ 实际位置 ≤ 上限 → OutResult = true
                               否则 → OutResult = false + 失败原因
```

**输出:** OutResult, OutPosition, OutFailReason

### 3.7 软着陆 (SoftLanding)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 动作类型 | Enum | — | SoftLanding |
| 6 | 加速度(mm/s²) | double | 1000 | 快进/回退的加速度 |
| 7 | 减速度(mm/s²) | double | 1000 | 快进/回退的减速度 |
| 8 | 扭矩正向限制(峰值电流1/10000) | int | 1000 | 控制最大出力，驱动器在探测阶段受此限制 |
| 9 | 二段速度-探测速度(mm/s) | double | 5 | 探测接触的低速，越小精度越高 |
| 10 | 快进位置(mm) | double | — | 快速接近的目标位置 |
| 11 | 速度切换位置(mm) | double | — | 一段→二段切换位置 |
| 12 | 软着陆超时(秒) | int | 10 | 上位机层面的超时保护 |
| 13 | 回退位置(mm) | double | 0 | 保压后回退到的位置 |
| 14 | 最大行程限制(mm) | double | 20 | 超过此位置立即停止(安全保护) |
| 15 | 快进/回退速度(mm/s) | double | 50 | 快进和回退阶段的速度 |
| 16 | 一段速度-逼近速度(mm/s) | double | 20 | 接近产品的速度 |
| 24 | 力矩保持时间(ms) | int | 500 | 探测到接触后保压时长 |
| 25 | 判断停止时间(ms) | int | 100 | 判断停止的采样时间窗口 |
| 26 | 停止速度阈值(mm/s) | double | 0.5 | 速度低于此值判定为停止 |
| 27 | 压力标定系数K | double | 1.0 | 压力 = K × 0x201B原始值 + B |
| 28 | 压力标定偏移B | double | 0.0 | |

**执行流程:**
```
1. 写入力控参数-位置 (mm × PerPluse → 脉冲数):
   - 0x2009 → 回退位置
   - 0x200A → 快进位置
   - 0x200B → 速度切换位置
   - 0x200C → 最大行程限制

2. 写入力控参数-速度 (mm/s × PerPluse → 脉冲/s):
   - 0x200E → 一段速度(逼近)
   - 0x200F → 二段速度(探测)
   - 0x2010 → 快进/回退速度
   - 0x2012 → 加速度
   - 0x2013 → 减速度

3. 写入力控参数-判定:
   - 0x2011 → 停止速度阈值
   - 0x2014 → 力矩保持时间(ms)
   - 0x2015 → 判断停止时间(ms)

4. 写入扭矩限制:
   - 0x2017 → 扭矩正向限制
   - 0x2018 → 扭矩负向限制(与正向相同)

5. 确保 CSP 模式: 0x6060 = 8, 延时 50ms

6. 触发力控 (0x2016 上升沿):
   - 写 0x0F00 (bit8~11=1保持CSP, bit0=0)
   - 延时 10ms
   - 写 0x0F01 (bit0=1, 上升沿触发)

7. 轮询等待完成 (每 10ms):
   ├─ 读取 0x201A, 取 phase = state & 0x0F
   ├─ phase > 1 → 标记已启动
   ├─ 已启动 且 phase == 1 → 力控完成
   │   → OutPosition = 当前位置, OutPressure = 读取压力
   │   → OutResult = true, 返回
   └─ 超时 → OutResult = false
```

**力控状态机 (0x201A bit0~3):**

| phase | 阶段 | 说明 |
|-------|------|------|
| 1 | 准备/完成 | 初始状态，或力控执行完毕(保压+回退完成) |
| 2 | 快进 | 以快进速度快速接近 |
| 3 | 一段速度 | 到达快进位置后，以一段速度逼近 |
| 4 | 二段速度(探测) | 到达速度切换位置后，以二段速度低速探测接触 |
| 6 | 回退 | 保压完成后，回退到回退位置 |

**力控控制字 (0x2016):**

| 值 | 含义 |
|----|------|
| 0x0000 | 复位(力控待机) |
| 0x0001 | bit0上升沿→启动开环力控 |
| 0x0002 | bit1上升沿→立即回退 |
| 0x0004 | bit2上升沿→立即停止 |
| 0x0100 | bit8=1→保持CSP模式(力控期间需置位) |
| 0x0F00 | bit8~11=1(推荐), bit0=0(待触发) |
| 0x0F01 | bit8~11=1 + bit0=1(触发) |
| 0x0F04 | bit8~11=1 + bit2=1(紧急停止) |

**输出:**
- OutResult: 是否成功
- OutPosition: 完成时的实际位置(mm)
- OutPressure: 完成时的实际压力(经K/B标定换算)
- OutFailReason: 超时时输出详细原因

**紧急停止:**
调用 `Stop()` 方法会:
1. 设置中断标志 `_isBreak = true`
2. 写 0x2016 = 0x0F04 (bit2=1 立即结束力控)
3. 调用 `_axis.Stop()` 停止轴运动

## 4. 压力标定流程

### 4.1 标定原理

钧舵音圈电机通过模拟量反馈(0x201Bh)间接测量压力:
```
压力 = K × 0x201B原始值 + B
```
0x201B 为 -32768~32767 的 int16 值，对应 -10V~10V 模拟量输入。

### 4.2 标定步骤

**准备工作:**
- 外部力传感器(精度 0.1g 或更高)
- 标定块

**标定流程:**
1. 电机回零并使能
2. 执行软着陆(使用较小扭矩限制)
3. 记录 0x201B 原始值和力传感器实际读数
4. 修改扭矩限制，重复多组数据

**标定数据示例:**

| 次数 | 0x201B原始值 | 力传感器(g) |
|------|-------------|------------|
| 1 | 500 | 120 |
| 2 | 1000 | 245 |
| 3 | 1500 | 368 |
| 4 | 2000 | 492 |
| 5 | 2500 | 615 |

拟合结果: K ≈ 0.247, B ≈ -3.2

## 5. 典型工艺流程

### 5.1 开机初始化

```
Step 1: 使能 (ServoOn)
Step 2: 回零 (Home) 或 非标回零 (HomeNonStandard)
```

### 5.2 压装工艺

```
Step 1: 硬着陆 (HardLanding) → 移动到接近产品的安全位置(可选)
Step 2: 软着陆 (SoftLanding) → 驱动器自主完成力控压装
         - 快进位置: 产品表面上方约5mm
         - 速度切换位置: 产品表面上方约1mm
         - 一段速度: 10-20mm/s
         - 二段速度: 2-5mm/s (探测速度，越小精度越高)
         - 扭矩限制: 根据目标压力设定
         - 保压时间: 300-1000ms
         - 回退位置: 0mm
Step 3: 硬着陆 (HardLanding) → 移动到安全位置
```

### 5.3 异常恢复

```
Step 1: 复位 (Reset) → 清除报警并重新使能
Step 2: 根据需要重新回零或继续操作
```

### 5.4 关机

```
Step 1: 硬着陆 (HardLanding) → 移动到安全位置
Step 2: 失能 (ServoOff)
```

## 6. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 使能失败 | 驱动器硬件异常 | 检查接线，尝试复位 |
| SDO 读写失败 | 板卡未初始化/从站号错误 | 检查板卡初始化和轴号配置 |
| 回零超时 | 回零参数不合理 | 检查回零模式和速度设置 |
| 软着陆不触发 | CSP 模式未就绪 | 确认 0x6060 = 8 已写入 |
| 软着陆一直不完成 | 扭矩限制太大/太小 | 调整扭矩限制参数 |
| 软着陆超时 | 扭矩不够导致探测不到接触 | 增大扭矩限制或减小二段速度 |
| 压力值异常 | 标定系数K/B未配置 | 先完成压力标定 |

## 8. 调用链

### 8.1 整体调用架构

```
用户任务流 (TaskFlow)
  └─ JunRudderVCM.DoExcute()
       ├─ GetVDevice<VAxis>(DeviceParam, out _axis)   // 解析轴设备
       └─ switch(ActionType)
            ├─ ExecuteServoOn()      → _axis.ServOn(true)
            ├─ ExecuteReset()        → _axis.ResetStatus()
            ├─ ExecuteServoOff()     → _axis.ServOn(false)
            ├─ ExecuteHome()         → _axis.Home() + _axis.CheckHomeDone()
            ├─ ExecuteHomeNonStandard() → SDOWrite(0x6098/0x6099/0x609A) + _axis.Home() + _axis.CheckHomeDone()
            ├─ ExecuteHardLanding()  → _axis.MoveAbs() + _axis.CheckMotionDone()
            └─ ExecuteSoftLanding()  → _axis.SDOWrite() + _axis.SDORead() 轮询
```

### 8.2 软着陆 SDO 调用链

```
JunRudderVCM.ExecuteSoftLanding()
  │
  ├─ _axis.SDOWrite(index, subindex, data, data_size)
  │     └─ VAxis.SDOWrite()
  │           └─ GGMotionCard.SDOWrite()
  │                 ├─ CheckInit()
  │                 ├─ GetAxisNum(slave → coreNum, axisNum)
  │                 └─ SafeNativeMethod → mc.GTN_EcatSDODownload(core, axisNum, ...)
  │
  └─ _axis.SDORead(index, subindex, data_size, out value, count)
        └─ VAxis.SDORead()
              └─ GGMotionCard.SDORead()
                    ├─ CheckInit()
                    ├─ GetAxisNum(slave → coreNum, axisNum)
                    └─ SafeNativeMethod → mc.GTN_EcatSDOUpload(core, axisNum, ...)
```

### 8.3 轴号映射

```
外部轴号 (AxisNo, 从1开始)
  └─ GGMotionCard.GetAxisNum()
       ├─ axisNo ∈ [1, axisCountCore1]       → core=coreNum1(1), axisNum=axisNo
       └─ axisNo ∈ (axisCountCore1, total]   → core=coreNum2(2), axisNum=axisNo-axisCountCore1

固高 SDK 参数映射:
  core     → short (内核号, 1 或 2)
  axisNum  → ushort (EtherCAT 从站编号)
```

## 9. 输出参数说明

所有动作共享以下输出参数(只读):
