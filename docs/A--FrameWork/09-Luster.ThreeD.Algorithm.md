## 项目简介

`Luster.ThreeD.Algorithm` 提供**3D 几何运算和算法**，支持点云、曲面拟合、空间变换等三维视觉和测量领域的计算需求。允许 `AllowUnsafeBlocks` 以优化内存操作性能。

## 核心职责

- 3D 几何运算（点云处理、空间变换）
- 曲面拟合与测量算法
- 高性能数值计算（unsafe 代码支持）
