# DHRoboticsVCM 使用 SOP

> 大寰(DH Robotics) SAC-N2 驱动器 + DLAR-20-40 ZR 执行器
> 通信: EtherCAT(CIA402) via 凌臣 PCI-M60 板卡
> 参考文档: SAC-N2-音圈&凌臣PCI系列控制卡工业适配技术样本 v001.3

---

## 1. 硬件与接线

### 1.1 系统组成

| 组件 | 型号 | 说明 |
|------|------|------|
| 控制卡 | 凌臣 PCI-M60 / PCIe-M60 | EtherCAT 主站 |
| 驱动器 | SAC-N2-EC-24U-03 A1 03 A1-0 | 双通道伺服驱动 |
| 执行器 | DLAR-20-40 ZR | 音圈电机 + 编码器 |

### 1.2 执行器版本差异

| 版本 | Z轴回零模式 | R轴回零模式 | Z轴信号 |
|------|------------|------------|---------|
| 光栅版(H1) | -3(碰挡板找Z脉冲) | 33/34 | 不需要原点信号 |
| 磁栅版(M2) | 19(原点开关下降沿) | 33/34 | 需要原点信号(DI2) |

### 1.3 接线要点

- 光栅版本: Z轴不需要原点信号线，只需电源线和编码器线
- 磁栅版本: Z轴需要接原点信号，使用 IO 接口的第7针(INPUT2)和第18针(输入公共端)
- 制动电阻: 非必须，音圈电机一般不使用

### 1.4 EtherCAT 配置

参考文档 P20-23:
1. 安装凌臣上位机软件，找到 ENI 文件目录
2. 使用 Visual Studio 编辑 `eni.xml`:
   - 找到 `SAC MultiAxis` 项目
   - 在 TxPDO 中添加需要读取的对象(如 0x606C 速度、0x6077 电流)
   - RxPDO 一般不需要修改
   - 修改后确认 Send 和 Recv 字节数一致
3. 覆盖原目录的 `eni.xml`，重新连接总线

## 3. 各动作详细说明

### 3.1 使能 (ServoOn)

**调用:** `_axis.ServOn(true)`

**内部流程:**
1. 检测轴是否报警(状态 bit 0x02)
2. 若有报警，调用 M_ClrSts 清除
3. 调用 `M_Servo_On` 完成 CIA402 状态机切换:
   - Switch on disabled → Ready to switch on → Switch on → Operation enabled

**使用时机:** 开机后、运动前必须先使能

---

### 3.2 复位 (Reset)

**调用:** `_axis.ResetStatus()`

**内部流程:** ClearError(清除报警) + ServOn(重新使能)

**使用时机:** 轴报警后恢复，不需要重新手动使能

---

### 3.3 失能 (ServoOff)

**调用:** `_axis.ServOn(false)`

**使用时机:** 维护、停机时

---

### 3.4 常规回零 (Home)

**调用:** `_axis.Home()` + `_axis.CheckHomeDone(HomeTimeout)`

**内部流程:**
1. ResetState(清错+使能)
2. 设置回零参数(速度/加速度等，使用轴配置中的参数)
3. 切换回零模式(6060h = 6)
4. 启动回零
5. 等待完成，自动切回 CSP 模式(6060h = 8)

**适用场景:** 使用轴配置中预设的回零参数，标准 CIA402 回零

**注意事项:**
- 回零参数(模式/速度/加速度)在轴配置中设置，不在 Function 参数中
- 回零过程中不支持暂停

---

### 3.5 非标回零 (HomeNonStandard)

**文档依据:** 大寰文档 P32-34

**为什么需要非标回零?**
> 凌臣标准回零方法无法有效传入回零堵转电流、堵转时间等关键参数，
> 所以推荐使用非标回零方法。

**执行顺序:**
```
1. 速度/加速度单位转换 (mm/s × PerPluse → pls/s)
2. M_SetHomingPrm(模式=34占位)     ← 先用假模式设参数
3. M_SetHomingMode(6)               ← 切换到回零模式
4. SDO 写入:
   - 0x6098   → 正确回零模式(如 -3/19)
   - 0x5000.05 → 碰撞回零电流阈值(千分比)
   - 0x5000.06 → 电流检测时间(ms)
5. M_HomingStart                     ← 启动回零
6. M60_WaitHoming                    ← 等待完成(自动切回CSP)
```

**参数说明:**

| 参数 | SDO地址 | 单位 | 默认值 | 说明 |
|------|---------|------|--------|------|
| 回零模式 | 0x6098 | — | 0 | 光栅:-3, 磁栅:19, R轴:33/34 |
| 回零高速 | 0x6099.1 | mm/s | 50 | 快速搜索速度 |
| 回零低速 | 0x6099.2 | mm/s | 10 | 慢速搜索速度 |
| 回零加速度 | 0x609A | mm/s² | 1000 | |
| 碰撞电流阈值 | 0x5000.05 | 千分比 | 500 | 500=0.5倍额定电流 |
| 电流检测时间 | 0x5000.06 | ms | 100 | 检测到碰撞电流持续多久判定为堵转 |
| 回零超时 | — | 秒 | 60 | |

**错误码:**

| 错误码 | 含义 |
|--------|------|
| -11 | 回零超时 |
| -12 | 回零完成但模式切换失败(未能切回CSP) |

**典型配置示例:**

光栅版本 Z 轴碰撞回零:
```
回零模式 = -3 (负向碰挡板反向找Z脉冲)
碰撞电流阈值 = 500 (0.5倍额定电流)
电流检测时间 = 100ms
```

磁栅版本 Z 轴碰撞回零:
```
回零模式 = 19 (正向原点开关下降沿)
碰撞电流阈值 = 500
电流检测时间 = 100
```

### 3.6 硬着陆 (HardLanding)

**流程:**
```
MoveAbs(目标位置, 速度, 加速度, 减速度) → CheckMotionDone → 判断位置是否在范围内
```

**参数:**

| 参数 | 说明 |
|------|------|
| 目标位置 | 绝对位置(mm) |
| 运动速度 | mm/s |
| 加速度/减速度 | mm/s² |
| 位置上限/下限 | 到位判断范围(mm) |

**输出:**
- OutResult: 位置是否在[下限, 上限]范围内
- OutPosition: 实际位置
- OutFailReason: 失败原因(位置超限时输出)

---

### 3.7 软着陆 (SoftLanding)

**文档依据:** 大寰文档 P50 (8.1 力控模式)

**原理:**
> CSP位置模式 + 电流限制，无压力传感器，
> 通过电流反馈(0x6077)间接推算压力，故称开环力控。

**关键地址:**

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x5018 | 电流限制(轴一) | 千分比，写入限制值 |
| 0x6077 | 电流反馈(轴一) | 千分比，读取实际值 |
| 0x5818 | 电流限制(轴二) | 轴二在轴一基础上+0x800 |
| 0x6877 | 电流反馈(轴二) | 同上 |

**执行流程:**
```
1. 备份默认电流限制(0x5018)
2. [可选] 快速接近中间点位(MoveAbs)
3. 计算目标压力对应的电流限制值: 电流 = (目标压力 - B) / K
4. 写入电流限制(0x5018)
5. MoveAbs(目标位置, 压入速度) 启动慢速压入
6. 轮询循环(每10ms):
   ├─ 读取: 位置, 电流(0x6077), 速度(位置差分)
   ├─ 成功判定: |电流 - 限制| ≤ 容差 AND 速度 ≤ 阈值
   │   → Stop → 记录位置/压力 → OutResult = true
   ├─ 防撞保护: 位置 ≥ 上限
   │   → Stop → OutResult = false
   └─ 超时 → Stop → OutResult = false
7. finally: 恢复默认电流限制(0x5018)
```

**参数说明:**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标压力设定值 | 期望达到的压力(经标定后的值) | — |
| 压力上限 | 防撞保护上限 | — |
| 压力下限 | 压力窗口下限 | — |
| 压入速度 | 慢速压入速度 | — |
| 软着陆超时 | 秒 | 10 |
| 电流匹配容差 | 0x6077与0x5018的允许偏差 | 10 |
| 速度判定阈值 | mm/s，低于此值认为已停止 | 0.5 |
| 标定系数K | 压力 = K × 电流 + B | 1.0 |
| 标定偏移B | 线性标定截距 | 0.0 |
| 启用多段运动 | 是否先快进到中间点位 | false |
| 中间点位 | 快速接近位置(mm) | — |

**成功判定逻辑(文档P50):**

条件1: `|0x6077 - 0x5018| ≤ 电流匹配容差`
> 实际电流接近限制值，说明电机已压到产品，电流达到上限

条件2: `速度 ≤ 速度判定阈值`
> 电机已停止运动，压力稳定

两个条件同时满足 → 判定软着陆成功

**输出:**
- OutResult: 是否成功
- OutPosition: 停止时的实际位置(mm)
- OutPressure: 停止时的实际压力(经标定换算)

## 4. 压力标定流程

**文档依据:** 大寰文档 P52-53 (8.1.4 力控标定)

### 4.1 标定原理

大寰音圈电机没有压力传感器，通过电流反馈(0x6077)间接推算压力:
```
压力 = K × 0x6077电流值 + B
```

### 4.2 标定步骤

**准备工作:**
- 精度 0.1g 或 0.01g 的压力传感器
- 压力标定块(模拟实际来料高度)
- 力传感器高度调到与产品高度一致

**标定流程:**
1. 电机回零，回零完成后失能
2. 将Z轴往下拉，直到轴末端与力传感器接触，记录电机位置(如 15mm)
3. 设定 0x5018 为一个初始值(如 500)，代表目标力 500g
4. 设置速度约 10mm/s，目标位置 17mm(比接触位置大2mm确保能压到)
5. 执行压入，等待压力传感器读数稳定(1-3秒)，记录:
   - 0x5018 设定值
   - 力传感器显示的实际力(g)
6. 回退到 0mm 位置
7. 重复步骤3-6，修改 0x5018 值，记录多组数据

**标定数据示例(目标500g):**

| 次数 | 0x5018设定值 | 力传感器(g) |
|------|-------------|------------|
| 1 | 500 | 490 |
| 2 | 505 | 491 |
| 3 | 512 | 497 |
| 4 | 520 | 505 |
| 5 | 525 | 507 |

### 4.3 计算标定系数

使用最小二乘法拟合线性关系:
```
力传感器(g) = K × 0x5018 + B
```

以上数据为例: K = 7.479, B = 114.785

**反向使用(设定目标压力):**
- 想输出 500g 压力 → 0x5018 = (500 - 114.785) / 7.479 ≈ 51.4%
- 当前 0x6077 反馈 500 → 实际压力 = 7.479 × 500 + 114.785 = 488.79g

**在 Function 中填入:**
- 标定系数K = 7.479
- 标定偏移B = 114.785
- 目标压力设定值 = 期望的力(g)

## 5. 典型工艺流程

### 5.1 开机初始化

```
Step 1: 使能 (ServoOn)
Step 2: 非标回零 (HomeNonStandard) 或 常规回零 (Home)
```

### 5.2 压装工艺

```
Step 1: 硬着陆 (HardLanding) → 移动到接近产品的位置
Step 2: 软着陆 (SoftLanding) → 压装(多段运动+力控)
         - 启用多段运动: true
         - 中间点位: 产品表面上方约1mm
         - 目标位置: 超过产品表面约2mm(确保能压到)
         - 压入速度: 5-10mm/s
         - 电流限制: 根据标定系数换算
Step 3: 硬着陆 (HardLanding) → 移动到安全位置
```

### 5.3 异常恢复

```
Step 1: 复位 (Reset) → 清除报警并重新使能
Step 2: 根据需要重新回零或继续操作
```

### 5.4 关机

```
Step 1: 移动到安全位置 (HardLanding)
Step 2: 失能 (ServoOff)
```

## 6. 故障排查

### 6.1 常见错误

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 使能失败 | 驱动器硬件异常 | 检查接线，尝试复位 |
| 回零启动失败 | 模式切换失败 | 检查总线连接 |
| 回零超时 | 碰撞电流/时间设置不合理 | 调整碰撞电流阈值和检测时间 |
| 回零模式切换失败 | CSP模式切换异常 | 检查总线状态 |
| 软着陆超时 | 电流限制太小/压入速度太慢 | 增大电流限制或调整速度 |
| 软着陆防撞停止 | 目标位置设置过大 | 减小目标位置或增大位置上限 |
| 软着陆误判成功 | 电流容差过大/速度阈值过大 | 减小电流匹配容差和速度阈值 |

### 6.2 SDO 地址速查

| 地址 | 名称 | 读/写 | 用途 |
|------|------|-------|------|

| 0x6060 | 运行模式 | R/W | 6=回零, 8=CSP |
| 0x6077 | 电流反馈 | R | 千分比，压力推算来源 |
| 0x6098 | 回零模式 | R/W | -3/19/33/34 |
| 0x6099.1/2 | 回零高/低速 | R/W | pls/s |
| 0x609A | 回零加速度 | R/W | pls/s² |
| 0x607C | 回零偏置 | R/W | pls |
| 0x5000.05 | 碰撞回零电流阈值 | R/W | 千分比 |
| 0x5000.06 | 电流检测时间 | R/W | ms |
| 0x5018 | 电流限制(轴一) | R/W | 千分比 |
| 0x5818 | 电流限制(轴二) | R/W | 千分比 |
