# DHRoboticsVCM 使用 SOP

> 大寰(DH Robotics) SAC-N2 双轴驱动器 + DLAR-20-40 ZR 执行器
> 通信: EtherCAT(CIA402) via 凌臣 PCI-M60 板卡
> 参考文档: SAC-N2-音圈&凌臣PCI系列控制卡工业适配技术样本 v001.3
> 参考Demo: DH_Control_Demo_250522

---

## 1. 硬件与接线

### 1.1 系统组成

| 组件 | 型号 | 说明 |
|------|------|------|
| 控制卡 | 凌臣 PCI-M60 / PCIe-M60 | EtherCAT 主站 |
| 驱动器 | SAC-N2-EC-24U-03 A1 03 A1-0 | 双通道伺服驱动(一拖二) |
| 执行器 | DLAR-20-40 ZR | 音圈电机 + 编码器 |

### 1.2 SAC-N2 双轴控制器

SAC-N2 为一拖二双轴控制器，单个从站可控制两台电机：
- **轴一(NUM1)**: SDO 基地址，如 0x5018(电流限制)、0x6077(电流反馈)
- **轴二(NUM2)**: SDO 地址 +0x800 偏移，如 0x5818(电流限制)、0x6877(电流反馈)

在 Function 中通过"轴ID选择"参数区分。

### 1.3 双轴 SDO 地址映射

| 功能 | 轴一(NUM1) | 轴二(NUM2) | 偏移 |
|------|-----------|-----------|------|
| 回零方式 | 0x6098 | 0x6898 | +0x800 |
| 碰撞电流 | 0x5000.05 | 0x5800.05 | +0x800 |
| 碰撞时间 | 0x5000.06 | 0x5800.06 | +0x800 |
| 电流限制 | 0x5018 | 0x5818 | +0x800 |
| 电流反馈 | 0x6077 | 0x6877 | +0x800 |

> 0x6040(控制字)/0x6041(状态字) 为 CIA402 标准对象，板卡层通过轴号区分，不需要偏移。

### 1.4 执行器版本差异

| 版本 | Z轴回零模式 | R轴回零模式 | Z轴信号 |
|------|------------|------------|---------|
| 光栅版(H1) | -3对应252(碰挡板找Z脉冲) | 33/34 | 不需要原点信号 |
| 磁栅版(M2) | 19(原点开关下降沿) | 33/34 | 需要原点信号(DI2) |

### 1.5 接线要点

- 光栅版本: Z轴不需要原点信号线，只需电源线和编码器线
- 磁栅版本: Z轴需要接原点信号，使用 IO 接口的第7针(INPUT2)和第18针(输入公共端)
- 制动电阻: 非必须，音圈电机一般不使用

### 1.6 EtherCAT 配置

参考文档 P20-23:
1. 安装凌臣上位机软件，找到 ENI 文件目录
2. 使用 Visual Studio 编辑 `eni.xml`:
   - 找到 `SAC MultiAxis` 项目
   - 在 TxPDO 中添加需要读取的对象(如 0x606C 速度、0x6077 电流)
   - RxPDO 一般不需要修改
   - 修改后确认 Send 和 Recv 字节数一致
3. 覆盖原目录的 `eni.xml`，重新连接总线

## 2. 动作类型总览

| 动作类型 | 枚举值 | 说明 | 典型用途 |
|----------|--------|------|----------|
| 使能 | ServoOn | 伺服使能 | 开机初始化 |

### 3.4 常规回零 (Home)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 轴ID选择 | Enum | NUM1 | NUM1=轴一, NUM2=轴二 |

### 3.5 非标回零 (HomeNonStandard)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 轴ID选择 | Enum | NUM1 | NUM1=轴一, NUM2=轴二 |
| 2 | 动作类型 | Enum | — | HomeNonStandard |
| 21 | 回零超时(秒) | int | 60 | 等待回零完成的超时时间 |
| 22 | 回零模式代码 | short | 0 | CIA402回零方式，光栅:-3, 磁栅:19, R轴:33/34 |
| 23 | 回零高速(mm/s) | double | 50 | 快速搜索速度，内部乘PerPluse转为脉冲/s |
| 24 | 回零低速(mm/s) | double | 10 | 慢速搜索速度，内部乘PerPluse转为脉冲/s |
| 25 | 回零加速度(mm/s²) | double | 1000 | 内部乘PerPluse转为脉冲/s² |
| 26 | 碰撞回零电流阈值(千分比) | int | 500 | 检测到多大电流判定为碰撞，500=0.5倍额定电流 |
| 27 | 碰撞电流检测时间(ms) | int | 100 | 碰撞电流持续多久才判定为堵转 |

**执行顺序(与客户Demo一致):**
```
1. 速度/加速度单位转换 (mm/s × PerPluse → pls/s)
2. M_SetHomingPrm(模式=34占位)     ← 先用假模式设速度/加速度参数
3. SDO 写入(先写参数再切模式):
   - Addr(0x6098)   → 回零模式代码
   - Addr(0x5000).06 → 碰撞电流检测时间(ms)
   - Addr(0x5000).05 → 碰撞回零电流阈值(千分比)
4. M_SetHomingMode(6)               ← 切换到回零模式
5. M_HomingStart                     ← 启动回零
6. M60_WaitHoming                    ← 等待完成(自动切回CSP)
```

**错误码:**

| 错误码 | 含义 |
|--------|------|
| -11 | 回零超时 |
| -12 | 回零完成但模式切换失败(未能切回CSP) |

### 3.6 硬着陆 (HardLanding)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 轴ID选择 | Enum | NUM1 | NUM1=轴一, NUM2=轴二 |
| 2 | 动作类型 | Enum | — | HardLanding |
| 3 | 目标位置(mm) | double | — | 绝对定位的目标位置 |
| 4 | 位置上限(mm) | double | — | 到位后实际位置的上限判断值 |
| 5 | 位置下限(mm) | double | — | 到位后实际位置的下限判断值 |
| 6 | 运动速度(mm/s) | double | 50 | 运动过程中的速度 |
| 7 | 加速度(mm/s²) | double | 1000 | 运动加速度 |
| 8 | 减速度(mm/s²) | double | 1000 | 运动减速度 |

**内部流程:**
```
MoveAbs(目标位置, 运动速度, 加速度, 减速度)
→ CheckMotionDone(等待运动完成)
→ 读取实际位置
→ 判断: 下限 ≤ 实际位置 ≤ 上限 → OutResult = true
                               否则 → OutResult = false + 失败原因
```

**输出:** OutResult, OutPosition, OutFailReason

### 3.7 软着陆 (SoftLanding)

**界面可见参数:**

| 序号 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 0 | 轴设备选择 | VAxis | — | 选择对应的VAxis轴 |
| 1 | 轴ID选择 | Enum | NUM1 | NUM1=轴一, NUM2=轴二 |
| 2 | 动作类型 | Enum | — | SoftLanding |
| 7 | 加速度(mm/s²) | double | 1000 | PP段和PT段共用的运动加速度 |
| 8 | 减速度(mm/s²) | double | 1000 | PP段和PT段共用的运动减速度 |
| 9 | 快进位置PP(mm) | double | — | 快速接近产品的目标位置，应设为产品上方安全距离 |
| 10 | 快进速度(mm/s) | double | 50 | PP段(快速接近)的运动速度 |
| 11 | 接触位置PT(mm) | double | — | 低速接触产品的目标位置，应超过产品表面确保能压到 |
| 12 | 接触速度(mm/s) | double | 5 | PT段(低速接触)的运动速度，越小精度越高 |
| 13 | 扭矩限制(千分比) | int | 500 | PT段的电流输出上限，500=50%额定电流，控制最大出力 |
| 14 | 保压时间(ms) | int | 100 | 力矩到达后保持压力的时长 |
| 15 | 返回位置PB(mm) | double | 0 | 保压完成后快速返回的待机位置 |
| 16 | 软着陆超时(秒) | int | 10 | PT段等待力矩到达的最大时间 |
| 17 | 力矩到达容差(千分比) | int | 20 | 判定"力矩到达"时0x6077与扭矩限制的允许偏差 |
| 18 | 速度判定阈值(mm/s) | double | 1.0 | 判定"已停止"的速度阈值，与力矩容差共同决定接触判定 |
| 19 | 压力标定系数K | double | 1.0 | 压力换算公式的系数，压力 = K × 0x6077电流值 + B |
| 20 | 压力标定偏移B | double | 0.0 | 压力换算公式的偏移量 |

**执行流程(7步状态机):**
```
Step 0:  备份当前扭矩限制(0x5018) → 写入最大值3000
Step 10: 快进段 → MoveAbs(PP位置, PP速度, 加速度, 减速度) → 等待到位
Step 20: 写入扭矩限制为目标值(如500)
Step 30: 接触段 → MoveAbs(PT位置, PT速度, 加速度, 减速度)
         ├─ 轮询等待(每10ms, 不超过软着陆超时):
         │   读取 0x6077(电流反馈) + 位置(计算速度)
         │   判定: |电流 - 扭矩限制| ≤ 力矩到达容差 AND 速度 ≤ 速度判定阈值
         │   → 力矩到达, 进入保压
         └─ 超时 → Stop → 失败(OutFailReason含超时信息)
Step 40: 保压(保压时间 毫秒)
Step 50: 返回段 → MoveAbs(PB位置, PP速度, 加速度, 减速度)
         等电机离开接触面0.5mm后，写回扭矩限制为最大值3000(避免突然释放导致过冲)
         等待到位
Step 100: finally恢复备份的扭矩限制 → OutResult = true
```

**客户典型配置:**
```
PP位置=15.000, PP速度=1000.0, 加速度=30000.0
PT位置=16.000, PT速度=20.0, 扭矩限制=500
保压时间=100ms, 返回位置=0.000
```

**输出:**
- OutResult: 是否成功
- OutPosition: 返回后的实际位置(mm)
- OutPressure: 保压时的压力值(= 电流 × K + B)

## 4. 压力标定流程

### 4.1 标定原理

大寰音圈电机没有压力传感器，通过电流反馈(0x6077)间接推算压力:
```
压力(g) = K × 0x6077电流值(千分比) + B
```
标定系数K和B在软着陆参数中设置(序号19/20)。

### 4.2 标定步骤

**准备工作:**
- 精度 0.1g 或 0.01g 的压力传感器
- 压力标定块(模拟实际来料高度)

**标定流程:**
1. 电机回零并使能
2. 手动将Z轴拉到与力传感器接触，记录电机位置(如15mm)
3. 使用软着陆执行压入，修改不同扭矩限制值，记录力传感器实际读数
4. 多组数据线性拟合得到K和B

**标定数据示例:**

| 次数 | 扭矩限制(千分比) | 力传感器(g) | 0x6077反馈 |
|------|-----------------|------------|-----------|
| 1 | 300 | 290 | ~300 |
| 2 | 500 | 490 | ~500 |
| 3 | 700 | 688 | ~700 |
| 4 | 900 | 891 | ~900 |
| 5 | 1100 | 1095 | ~1100 |

拟合结果: K ≈ 1.006, B ≈ -8.4

## 5. 典型工艺流程

### 5.1 开机初始化

```
Step 1: 使能 (ServoOn)
Step 2: 非标回零 (HomeNonStandard) 或 常规回零 (Home)
```

### 5.2 压装工艺

```
Step 1: 软着陆 (SoftLanding)
         - PP位置: 产品表面上方约5mm (如15.000)
         - PP速度: 50-1000mm/s (快进)
         - PT位置: 超过产品表面约1-2mm (如16.000)
         - PT速度: 5-20mm/s (低速接触)
         - 扭矩限制: 根据目标力设定 (如500=50%额定电流)
         - 保压时间: 100-500ms
         - PB位置: 0mm (返回待机位置)
```

### 5.3 异常恢复

```
Step 1: 复位 (Reset) → 清除报警并重新使能
Step 2: 根据需要重新回零或继续操作
```

### 5.4 关机

```
Step 1: 硬着陆 (HardLanding) → 移动到安全位置
Step 2: 失能 (ServoOff)
```

## 6. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 使能失败 | 驱动器硬件异常 | 检查接线，尝试复位 |
| 回零启动失败 | 模式切换失败 | 检查总线连接 |
| 回零超时 | 碰撞电流/时间设置不合理 | 调整碰撞电流阈值和检测时间 |
| 回零模式切换失败 | CSP模式切换异常 | 检查总线状态 |
| 软着陆力矩未到达 | 扭矩限制太小/接触速度太快 | 增大扭矩限制或减小接触速度 |
| 软着陆超时 | PT位置不够深/扭矩限制不够 | 增大PT位置或扭矩限制 |
| 软着陆返回过冲 | 离开接触面后才解除力矩 | 程序已处理(等0.5mm后解除) |
| SDO读写失败 | 板卡未初始化/从站号错误 | 检查板卡初始化和轴号配置 |

## 8. 输出参数说明

所有动作共享以下输出参数(只读):

| 序号 | 名称 | 类型 | 说明 |
|------|------|------|------|
| 30 | 执行结果 | bool | true=成功，false=失败(配合失败原因使用) |
| 31 | 实际位置(mm) | double | 硬着陆停止时的位置；软着陆返回后的位置 |
| 32 | 实际压力 | double | 软着陆保压时的压力值(经K/B标定换算)；其他动作为0 |
| 33 | 失败原因 | string | 失败时的详细描述；成功时为空 |
