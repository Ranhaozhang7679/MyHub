根因分析

参数名不匹配：代码中硬编码查找的参数 Key 与配方中实际定义的参数 Key 不一致。

DryRunEnable() 在全局参数字典中查找 Key 为 "Extend_空跑模式" 的参数， 但 CG11 配方中不存在这个参数。配方中实际代表空跑模式的参数 Key 是 "Extend_生产模式"。

修复方案

方案 A — 直接修复（快速）

将 DRYRUNNAME 改为配方中实际使用的参数 Key：

值
修改前 private string DRYRUNNAME = "Extend_空跑模式";
修改后 private string DRYRUNNAME = "Extend_生产模式";

⚠ 注意：此方案仅适用于当前项目。若其他项目的配方使用不同参数名，需逐一适配。

方案 B — 从配置动态读取（推荐）

从 SystemConfig.xml 的 ListGlobalVar 或 RunModeModel 中动态获取空跑模式对应的参数 Key，避免硬编码：

// 思路：遍历 RunModeModel，找到 Mode 包含 "空跑" 的配置项，
// 从其 SelectGlobalVar 中提取 IsSelected=True 的 GlobalKey
var emptyRunMode = sysConfig.ListRunMode
    .FirstOrDefault(m => m.Mode.Contains("空跑"));
var dryRunKey = emptyRunMode?.SelectGlobalVar
    .FirstOrDefault(g => g.GlobalName == "空跑模式")?.GlobalKey;

方案 C — 配方修正（可选）

将配方中 Extend_生产模式 的参数 Key 改为 Extend_空跑模式，使参数名与语义一致。但这需要同步修改所有引用该参数的配方节点，影响范围较大。
