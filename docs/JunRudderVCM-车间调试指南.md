# JunRudderVCM 车间调试指南

> 明天车间调试参考，梳理从板卡到电机的完整链路、调试顺序和常见问题。

---

## 1. 系统全链路

```
上位机软件 (LMV-2026)
  └─ JunRudderVCM (Function层)
       └─ VAxis (运动轴抽象层)
            └─ GGMotionCard (固高板卡驱动层)
                 └─ gts.dll (固高SDK, P/Invoke)
                      │
                      │  EtherCAT 总线 (网线)
                      │
                 ┌────┴────┐
                 │ GSFDmini │  (固高伺创 驱动器, EtherCAT从站)
                 └────┬────┘
                      │  电机动力线 + 编码器线
                      │
                 ┌────┴────┐
                 │钧舵音圈电机│  (含编码器 + 压力传感器模拟量)
                 └─────────┘
```

## 2. 调试顺序（从底层到上层）

### Step 0: 硬件接线检查

```
[固高板卡] ──网线──→ [GSFDmini EtherCAT口]
                        │
                        ├── 电机动力线 (U/V/W)
                        ├── 编码器线 (A+/A-/B+/B-/Z+/Z-/5V/GND)
                        ├── 24V电源 (给驱动器供电)
                        └── 模拟量输入 (压力传感器, 接C2接口 AIN1_P/AIN1_N)
```

**检查要点:**
- 24V电源是否接好（驱动器指示灯亮）
- EtherCAT网线是否连通（驱动器EtherCAT口LED亮）
- 编码器线是否紧固
- 电机动力线U/V/W是否对应

---

### Step 1: 驱动器基础配置（用固高伺创调试软件 DriverStudio）

**连接方式:** 网线直连驱动器调试口（IP: 192.168.1.100，电脑设同网段如 192.168.1.99）

**必须完成的配置:**

1. **烧写固件** — 确保驱动器固件版本匹配
2. **电机参数设置** — 填入钧舵电机的参数:

   | 参数 | 说明 | 单位 | 来源 |
   |------|------|------|------|
   | 额定电流 | 电机额定电流 | A(rms) | 电机手册 |
   | 峰值电流 | 瞬时最大电流 | A(峰值) | 电机手册或3×额定 |
   | 额定转速 | — | rpm | 电机手册 |
   | 最大转速 | — | rpm | 电机手册 |
   | 极对数 | — | — | 电机手册 |

3. **编码器设置** — 根据编码器类型配置:
   - 增量式: A/B/Z + 霍尔
   - 绝对值: 多摩川/尼康等
   - 输入分辨率: 决定 PerPluse 换算关系

4. **输入分辨率** — **非常重要！**
   - 这个值决定了 mm → 脉冲的换算系数 (PerPluse)
   - 例如: 电机丝杠导程5mm，编码器分辨率10000 → PerPluse = 10000/5 = 2000 脉冲/mm
   - 上位机 JunRudderVCM 中 `int pp = _axis.PerPluse` 就取的这个值
   - 所有SDO写入的位置/速度参数都要 ×PerPluse

---

### Step 2: 驱动器调参（PID调试）

**用固高伺创调试软件 DriverStudio 进行:**

顺序: ADC校正 → 电压开环 → 电流环 → 惯量辨识 → 速度环 → 位置环

**参考文档:** 固高驱动器-轴精度调试步骤说明-2025.6.12.pdf

**关键参数 (可通过SDO读写):**

| 地址 | 参数 | 说明 |
|------|------|------|
| 0x3000 | 位置环增益 | 0~1000 |
| 0x3001 | 速度环增益 | 1~1000 |
| 0x3002 | 速度环积分时间 | 0~655.35 |
| 0x3100 | 电机惯量 | 10⁻⁶ kg·m² |

**注意:** 如果上伺服电机摆动且啸叫，检查 0x200F 的 TQCP 位是否置1。

---

### Step 3: EtherCAT 总线通讯

**固高板卡侧:**

1. 用固高配置工具生成 ENI 文件
2. 确保 PDO 映射包含必要对象:

   **TxPDO (驱动器→上位机，必须映射):**
   | 地址 | 名称 | 用途 |
   |------|------|------|
   | 0x6041 | 状态字 | CIA402状态 |
   | 0x6064 | 位置反馈 | 实际位置 |
   | 0x201B | 压力反馈 | 模拟量读数 |

   **RxPDO (上位机→驱动器，一般默认即可):**
   | 地址 | 名称 | 用途 |
   |------|------|------|
   | 0x6040 | 控制字 | CIA402控制 |
   | 0x6060 | 运行模式 | 切换模式 |

3. 软着陆参数通过 SDO 实时写入，不需要在 ENI 中预映射

**验证通讯:**
```
GTN_Open → GTN_InitEcatComm → GTN_IsEcatReady → GTN_StartEcatComm
```
板卡指示灯/驱动器EtherCAT口绿灯常亮 = Operational 状态

---

### Step 4: 上位机软件控制 (JunRudderVCM)

**调试顺序:**

#### 4.1 使能 (ServoOn)
- 确保 EtherCAT 已进入 Operational 状态
- 调用 `_axis.ServOn(true)` → 驱动器应进入 Operation enabled
- 可以通过读 0x6041 确认状态字 = 0x1237

#### 4.2 回零 (Home / HomeNonStandard)
- 先用标准回零测试轴是否正常运动
- 如果需要自定义回零模式，用 HomeNonStandard (SDO写0x6098/0x6099/0x609A)
- 回零速度单位: mm/s × PerPluse → pulse/s

#### 4.3 硬着陆 (HardLanding)
- 先用低速测试，确认运动方向正确
- MoveAbs → 检查实际位置反馈是否正确

#### 4.4 软着陆 (SoftLanding) — 最关键

**调试流程:**

```
Step A: 先用固高伺创调试软件的力控功能确认驱动器侧力控正常
        (不经过上位机，直接在调试软件中触发力控)

Step B: 上位机写入力控参数 → 确认SDO写入成功
        (用调试软件的SDO浏览器回读确认)

Step C: 触发力控(0x2016上升沿) → 监控0x201A状态机

Step D: 全流程测试
```

**SDO参数写入验证:**
用固高伺创调试软件的 SDO 浏览器，回读上位机写入的值:
- 读 0x200A → 确认快进位置正确
- 读 0x200E → 确认一段速度正确
- 读 0x2017 → 确认扭矩限制正确

**0x201A 力控状态机对照:**

| phase | 阶段 | 说明 |
|-------|------|------|
| 1 | 准备/完成 | 力控待机或执行完毕 |
| 2 | 快进 | 快速接近 |
| 3 | 二段速探测 | 低速探测接触 |
| 4 | 接触状态 | 已接触到产品 |
| 6 | 回退 | 保压完成后回退 |

> 注意: Page 115手册中 bit0~3 的状态定义:
> - 0=未进入力控, 1=力控准备好, 2=二段速探测, 3=接触状态

**如果力控不触发:**
- 检查 0x6060 是否已写入 8(CSP模式)
- 检查 0x2016 的写入顺序: 先写0x0F00(复位), 等10ms, 再写0x0F01(触发)
- 检查驱动器是否处于 Operation enabled 状态

**如果力控一直不完成:**
- 检查扭矩限制是否合理（太小探测不到接触，太大可能过压）
- 检查快进位置、速度切换位置是否合理
- 检查二段速度是否太慢
- 读 0x201A 的完整16位值，看 bit12(停止标志) 和 bit13(压力到达标志)

## 3. 关键单位换算

这是最容易出错的地方，所有SDO通讯都需要单位换算:

| 上位机单位 | SDO单位 | 换算公式 | 例子 |
|-----------|---------|---------|------|
| mm | pulse | mm × PerPluse | 10mm × 2000 = 20000 pulse |
| mm/s | pulse/s | mm/s × PerPluse | 50mm/s × 2000 = 100000 pulse/s |
| mm/s² | pulse/s² | mm/s² × PerPluse | 1000 × 2000 = 2000000 |
| 扭矩限制 | 峰值电流1/10000 | 直接写入 | 1000 = 10%峰值电流 |
| 保压时间 | ms | 直接写入 | 500ms |
| 压力反馈 | -32768~32767 | K × 原始值 + B | 见标定流程 |

**扭矩限制单位详解:**
- 0x2017/0x2018 的单位是**峰值电流的1/10000**
- 这与 0x60E0/0x60E1 (额定电流的千分比) **单位不同**
- 例如: 电机峰值电流5000mA, 写入1000 → 限制 = 5000 × 1000/10000 = 500mA

## 4. 常见问题排查

| 现象 | 排查步骤 |
|------|---------|
| 板卡找不到驱动器 | 检查网线、ENI文件、GTN_InitEcatComm返回值 |
| 使能失败 | 读0x6041状态字，检查是否在Fault状态(bit3=1)，先清报警 |
| SDO读写失败 | 检查从站号(slaveInx)是否正确，EtherCAT是否Operational |
| 运动方向反了 | 修改编码器方向(Flash 0x21CE)或电机线交换U/V |
| 位置反馈不对 | 检查PerPluse设置、编码器分辨率、丝杠导程 |
| 力控不触发 | 确认CSP模式(0x6060=8)、0x2016上升沿时序 |
| 力控超时 | 增大扭矩限制、减小二段速度、检查位置参数是否合理 |
| 电流反馈波动大 | 检查总线周期与驱动器输入滤波器平滑时间(≥总线周期) |
| 驱动器报警 | 读0x603F错误码，查故障表(GSFDmini手册 §4.1) |
