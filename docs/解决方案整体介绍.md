# 项目配置文件说明

本文档介绍解决方案根目录下的配置文件及其用途。

---

## 1. `.editorconfig` — 编辑器代码风格配置

**用途**：统一所有开发者的代码格式风格，无论使用 VS、Rider 还是 VS Code。

**主要配置**：
- 4 空格缩进，CRLF 换行符
- 接口命名必须以 `I` 开头
- 类型、属性、方法使用 PascalCase
- `using` 指令放在命名空间外部

**开发提示**：IDE 会自动应用这些规则，无需手动关注。

---

## 2. `.gitignore` — Git 忽略规则

**用途**：告诉 Git 哪些文件不需要版本控制。

**忽略内容**：
- `artifacts/` — 构建输出目录
- `bin/`、`obj/` — 编译中间文件
- `.vs/`、`.idea/` — IDE 配置
- `*.user`、`*.suo` — 用户个人设置
- `appsettings.Development.json`、`secrets.json` — 敏感配置

**开发提示**：不要将这些文件提交到仓库。

---

## 3. `.gitlab-ci.yml` — GitLab CI/CD 流水线配置

**用途**：定义自动化流水线，包括通知和同步任务。

**当前功能**：
- 钉钉通知（推送、合并请求）
- 跨仓库 MR 同步

**注意**：构建任务目前已注释，如需启用请联系运维。

---

## 4. `Directory.Build.props` — 全局构建属性

**用途**：为所有项目统一设置构建属性，避免每个 `.csproj` 重复配置。

**主要配置**：
| 属性 | 值 | 说明 |
|------|-----|------|
| `TargetFramework` | `net472` | 目标框架 |
| `LangVersion` | `9.0` | C# 语言版本 |
| `BaseOutputPath` | `artifacts\bin\{项目名}\` | 统一输出目录 |
| `ManagePackageVersionsCentrally` | `true` | 启用中央包版本管理 |
| `GenerateDocumentationFile` | `true` | 自动生成 XML 文档 |

**开发提示**：新建项目无需配置这些属性，会自动继承。

---

## 5. `Directory.Build.targets` — 全局构建任务

**用途**：定义构建后的自动化任务，主要用于模块文件收集。

**核心功能**：
1. **模块项目**：将 DLL 拷贝到 `Devices/`、`Motions/`、`CardErrorCode/` 子目录
2. **Shell 项目**：收集所有模块的输出到根目录，形成扁平结构

**使用方式**（在 `.csproj` 中设置）：
```xml
<PropertyGroup>
    <!-- 拷贝 DLL 到 Devices 目录 -->
    <CopyToDevicesFolder>true</CopyToDevicesFolder>
    <!-- 拷贝 DLL 到 Motions 目录 -->
    <CopyToMotionsFolder>true</CopyToMotionsFolder>
    <!-- 标记为 Shell 主项目 -->
    <IsShellProject>true</IsShellProject>
</PropertyGroup>
```

---

## 6. `Directory.Packages.props` — 中央包版本管理

**用途**：统一管理所有 NuGet 包的版本号，避免版本冲突。

**工作机制**：
- 定义 `<PackageVersion Include="包名" Version="版本号" />`
- 项目中只需引用 `<PackageReference Include="包名" />`，无需指定版本

**示例**：
```xml
<!-- Directory.Packages.props 中定义 -->
<PackageVersion Include="Newtonsoft.Json" Version="13.0.2" />

<!-- 项目 .csproj 中使用 -->
<PackageReference Include="Newtonsoft.Json" />
```

**开发提示**：升级包版本时只需修改这一个文件。

---

## 7. `global.json` — .NET SDK 版本锁定

**用途**：指定项目使用的 .NET SDK 版本。

**当前状态**：已注释，使用本机安装的默认 SDK。

**启用方式**：取消注释并指定版本：
```json
{
  "sdk": {
    "version": "8.0.416",
    "rollForward": "latestFeature"
  }
}
```

---

## 8. `NuGet.config` — NuGet 包源配置

**用途**：配置 NuGet 包的下载源。

**配置的源**：
| 源名称 | 地址 | 用途 |
|--------|------|------|
| `local` | `.\packages` | 本地备用源 |
| `gitlab` | `http://10.9.1.153:8687/...` | Luster 内部包 |
| `nuget.org` | `https://api.nuget.org/...` | 公共包 |

**包源映射规则**：
- `Luster.*`、`HandyControl`、`HslCommunication` 等内部包 → 从 GitLab 获取
- 其他包 → 从 nuget.org 获取

## 常见问题

**Q: 新建项目需要修改这些文件吗？**
A: 通常不需要。新建项目会自动继承全局配置。

**Q: 如何添加新的 NuGet 包？**
A: 1) 在 `Directory.Packages.props` 添加版本定义；2) 在项目 `.csproj` 添加引用。

**Q: 构建输出在哪里？**
A: 所有输出统一在 `artifacts/bin/{项目名}/` 目录。
